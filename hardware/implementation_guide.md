# Rojin Z80 実装ガイド

技術記事 (Note/Zenn等) の執筆を目的とした、**PoC (Proof of Concept) 主導型開発** のための公式ガイドラインです。
本プロジェクトでは、プリント基板 (PCB) の作成は行わず、ブレッドボード上での実証実験を最終成果物とします。

## 1. 開発ロードマップ (Iterative Process)

全体を一度に構築するのではなく、以下のフェーズに分割して開発を進めます。各フェーズの成果が、そのまま技術記事の各章となります。

### Phase 1: The Heartbeat (クロック生成)
Z80を駆動するためのクロック信号をESP32から供給する仕組みを構築します。
- **目標**: ESP32単体で矩形波を生成し、安定性（ジッターや周波数精度）を検証する。
- **検証方法**: LED点滅による目視確認、またはロジックアナライザによる波形観測（オシロスコープは不要）。

### Phase 2: The Awakening (フリーラン)
Z80に電源とクロックを供給し、命令フェッチサイクルが機能することを確認します。
- **目標**: データバスに `NOP (0x00)` を固定入力し、Z80のアドレスバスが `0x0000` から `0xFFFF` まで順次カウントアップする様子を観測する。
- **実装**: ブレッドボード上でのESP32、レベルシフタ、Z80の物理配線。

### Phase 3: The Conversation (メモリ・エミュレーション)
ESP32を仮想メモリとして機能させ、Z80からのバスアクセスに応答するシステムを構築します。
- **目標**: Z80が発行したメモリアドレスをESP32が読み取り、対応する命令コードをデータバスに出力する。
- **実装**:
    - アドレスバス読み取りロジック（GPIO入力）
    - データバス書き込みロジック（GPIO出力、双方向制御）
    - バス調停（WAIT信号によるタイミング制御）

### Phase 4: The Consciousness (AI連携)
「意識」としてのAI (ChatGPT) と統合し、動的に生成されたコードを実行させます。
- **目標**: Wi-Fi経由で取得したZ80マシン語を、仮想メモリ領域に展開し実行する。

## 2. 開発環境・ツールセット

### A. 回路設計・配線図
**推奨ツール: [Fritzing](https://fritzing.org/)**
- **選定理由**: 記事読者への可読性を最優先し、実体配線図（ブレッドボード図）の作成に適したツールを採用します。

### B. ファームウェア (ESP32 Firmware)
本プロジェクトにおける「ファームウェア」とは、ESP32-S3上で動作する制御プログラムを指します。
ESP32は単なる周辺機器ではなく、システム全体の **「ホストコントローラ兼メモリデバイス」** として機能します。

- **主な役割**:
    1.  **システムクロック供給**: Z80へのクロック信号生成。
    2.  **バス・エミュレーション**: Z80のバスサイクル（MREQ, RD, WRなど）を監視し、メモリやI/Oとして振る舞う。
    3.  **ネットワーク通信**: Wi-Fi接続およびOpenAI APIとの通信。
- **開発環境**: **VS Code + PlatformIO**
    - 複雑なマルチタスク処理（Wi-Fi通信とマイクロ秒単位のバス制御の並立）が必要となるため、高度なデバッグ機能とライブラリ管理を持つPlatformIOを標準環境とします。
