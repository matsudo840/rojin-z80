# 老人Z80 回路図

## 1. システム全体ブロック図

```
┌─────────────────────────────────────────────────────────────┐
│                     電源供給系統                              │
├─────────────────────────────────────────────────────────────┤
│  USB 5V ──┬─→ Z80 (VCC)                                     │
│           ├─→ 74HC574 (VCC)                                 │
│           └─→ レベルシフタ A側 (5V入力)                      │
│                                                               │
│  ESP32 3.3V ─┬─→ レベルシフタ VCC (3.3V)                    │
│              └─→ レベルシフタ B側 (3.3V入力)                 │
│                                                               │
│  共通GND ────┴─ すべてのデバイスのGNDを接続                  │
└─────────────────────────────────────────────────────────────┘

┌──────────────┐
│   Z80 CPU    │  ← 老人（演算主体）
│  (5V駆動)    │
└──────────────┘
       │
       │ (神経接続: レベルシフタで電圧変換)
       │
       ↓
┌──────────────┐
│  LVC245 ×5   │  ← 神経系（5V ↔ 3.3V変換）
│ レベルシフタ  │
└──────────────┘
       │
       ↓
┌──────────────┐
│   ESP32-S3   │  ← 介護士（クロック供給、仮想メモリ、AI通信）
│  (3.3V駆動)  │
└──────────────┘
       │
       │ Wi-Fi
       ↓
   ChatGPT API
```

## 4. パスコン配置

```
各ICの電源ピン(VCC)とGND間に0.1μFセラミックコンデンサを配置:

・Z80: VCC(pin11) - GND(pin29)
・ESP32: 3V3ピン - GNDピン (複数箇所)
・LVC245 ×5: VCC(pin20) - GND(pin10) 各IC
・74HC574: VCC(pin20) - GND(pin10)
```

## 5. プルアップ抵抗配置

```
以下の信号線に10kΩプルアップ抵抗を5V電源に接続:

・Z80 データバス D0～D7 (8本)
・Z80 アドレスバス A0～A15 (16本)
・WAIT, RESET, MREQ, RD 信号
```

```
             ↑       ↑

             High: ESP32→Z80
```

## 補足事項

### レベルシフタ方向制御
- LVC245 の DIR (pin 1) が High: A→B (5V→3.3V)
- LVC245 の DIR (pin 1) が Low: B→A (3.3V→5V)

### 注意点
1. すべてのレベルシフタのOE (pin 19) はGNDに接続（常時有効）
2. Z80のINT, NMI, BUSREQはプルアップして未使用
3. 74HC574のOE (pin 1) はGNDに接続（常時出力有効）
