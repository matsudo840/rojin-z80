# 老人Z80 (RojinZ80) - ESP32-S3によるZ80 CPU介護プロジェクト

このレポジトリは、[エムスリーテックブック9](https://techbookfest.org/product/tQtQhhFVHnRkH0bFCUikYK?productVariantID=5prWVthbVuZMdKxmcTBut0) 第9章「老人Z80 — ESP32によるZ80 CPU介護ボード製作記」のサポートページです。

本プロジェクトは、1970年代の名機Z80 CPUを、現代のパワフルなマイコン ESP32-S3 によって構築されたソフトウェア空間（仮想バス）上で動作させる、最新鋭の装置による旧来の存在の介護をテーマにした電子工作プロジェクトです。

## コンセプト
1991年のアニメ映画『老人Z』に登場する全自動看護ベッド「Z-001」から着想を得ました。
物理的なROMやRAM、周辺ICを一切排除し、ESP32-S3が「メモリ」「I/O」「クロック供給」「制御バスの調停」の役割をすべてソフトウェアで代行します。

- Z80から見た世界: 40年前と同じように周辺回路に囲まれている。
- 現実: ESP32-S3のソフトウェアが作り出す仮想バス空間上で、1サイクルごとに歩調を合わせられながら動作している。

## システム構成
- CPU: Zilog Z84C0008PEC (CMOS版 Z80)
- 介護マイコン: ESP32-S3 (ESP32-S3-DevKitC-1等)
- レベルシフタ: 74LVC245 (5V系Z80と3.3V系ESP32の電圧変換)
- 周辺機器: I2C 128x64 OLED (SSD1306)

### 介護（エミュレート）の内容
1. クロック供給: ESP32のGPIOから規則的なパルスを供給。
2. 仮想メモリ: ESP32のRAM上に確保した64KBの配列をZ80のメモリ空間として提供。
3. 同期制御: `/WAIT` 信号を用いて、ESP32側の処理（メモリ読み書きやOLED描画）が終わるまでZ80を一時停止。
4. I/Oブリッジ: Z80のI/Oリクエストを検知し、現代のI2C OLEDディスプレイへ文字出力。

## ディレクトリ構成
- `firmware/`: ESP32-S3用のPlatformIOプロジェクト。
- `hardware/`: ピンアサイン、部品表(BOM)、回路図などのドキュメント。
- `examples/`: 開発ステップごとのファームウェア・スナップショット。
- `tools/`: ロジックアナライザの波形（VCD形式）を解析するPythonスクリプト。
- `images/`: 波形キャプチャや実行の様子。

## 使い方
### ファームウェアの書き込み
`firmware/` ディレクトリをPlatformIO（VSCode拡張機能等）で開き、ESP32-S3に書き込みます。

### Z80アセンブラの実行
`firmware/src/main.cpp` 内の仮想メモリ配列に、Z80のアセンブラをバイナリ形式で配置することで実行可能です。

## 解析ツール
`tools/` 内のスクリプトを使用することで、ロジックアナライザで取得した波形データから、Z80がどのように命令をフェッチし、実行しているかを解析できます。

```bash
python tools/parse_vcd_fetch.py data.vcd
```
